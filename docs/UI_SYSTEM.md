# UI_SYSTEM

# Главные принципы интерфейса

1. Интерфейс должен ощущаться быстрым.

2. Всё должно быть удобно на телефоне в первую очередь.

3. Интерфейс должен ощущаться как приложение, а не как сайт.

4. Пользователь не должен долго думать.

5. Важные действия должны быть очевидны сразу.

6. Меньше визуального шума — больше ясности.

7. Красота не должна мешать скорости и удобству.

8. Все экраны должны ощущаться частью одной системы.

---

# Главные ощущения интерфейса

Интерфейс должен ощущаться:

* быстрым;
* живым;
* современным;
* надёжным;
* цельным;
* app-like.

---

# Mobile First

1. Все новые решения сначала проверяются на телефоне.

2. Всё должно удобно нажиматься пальцем.

3. Нельзя делать маленькие touch-зоны.

4. Важные действия должны быть ближе к большому пальцу.

5. Пользователь не должен промахиваться по элементам.

6. Интерфейс должен работать одной рукой.

---

# Скорость интерфейса

1. Интерфейс должен ощущаться мгновенным.

2. Нельзя делать тяжёлые и медленные анимации.

3. Нельзя перегружать экран эффектами.

4. Любое действие должно давать быстрый визуальный отклик.

5. Всё лишнее убирается.

---

# Отступы

Маленький отступ:
6–8px

Средний:
12–16px

Большой:
20–24px

Правила:

* связанные элементы располагаются близко;
* разные блоки отделяются сильнее;
* интерфейс должен дышать;
* нельзя лепить элементы друг к другу.

---

# Скругления

Маленькие элементы:
10–14px

Карточки:
18–24px

Большие блоки:
24–32px

Интерфейс должен быть мягким, но не игрушечным.

---

# Карточки матчей

1. Главный элемент карточки — сам матч и прогноз.

2. Нельзя делать слишком много визуальных акцентов одновременно.

3. Декор не должен мешать чтению и взаимодействию.

4. Пользователь должен понимать структуру карточки за секунду.

5. Карточки должны ощущаться живыми и современными.

6. Карточки должны быть удобны именно на телефоне.

---

# Кнопки

1. Кнопки должны быть крупными и удобными.

2. Главные действия должны выделяться сразу.

3. Нельзя делать мелкие кнопки.

4. Кнопка должна выглядеть нажимаемой.

5. У кнопок должен быть быстрый визуальный отклик.

---

# Анимации

1. Анимации должны быть короткими и плавными.

2. Анимации нужны только там, где помогают ощущению интерфейса.

3. Нельзя делать анимации ради анимаций.

4. Интерфейс не должен ощущаться тяжёлым.

---

# Визуальная дисциплина

1. Все экраны должны выглядеть частью одного продукта.

2. Размеры элементов должны быть согласованы между собой.

3. Нельзя делать случайные размеры и отступы.

4. Нельзя перегружать интерфейс акцентами.

5. На экране всегда должен быть понятен главный элемент.

---

# Чего нельзя делать

1. Нельзя превращать интерфейс в перегруженную свалку.

2. Нельзя жертвовать скоростью ради красоты.

3. Нельзя добавлять декор ради декора.

4. Нельзя делать медленный интерфейс.

5. Нельзя ломать app-like ощущение.

6. Нельзя делать интерфейс, который требует долгого привыкания.

7. Нельзя допускать разные ощущения от разных экранов.

---

# Главная цель интерфейса

Сделать продукт:

* быстрым;
* удобным;
* живым;
* современным;
* цельным;
* и похожим на настоящее мобильное приложение, а не на обычный сайт прогнозов.
