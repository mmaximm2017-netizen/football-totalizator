# SMOKE_CHECKLIST

## После каждого деплоя

### Главная страница

- Главная страница открывается.
- Месяцы раскрываются и закрываются.
- Дни раскрываются и закрываются.
- Карточки матчей видны.

### Прогнозы

- Кнопки `+` и `-` меняют счёт.
- Ставку можно сохранить.
- После сохранения ставка видна на карточке.
- Закрытый матч нельзя изменить.

### Завершённые матчи

- Итоговый счёт виден.
- Очки видны.
- “Ставки игроков” открываются.

### Таблица

- Таблица открывается.
- Очки отображаются.

### Профиль

- Профиль открывается.
- Прогнозы видны.

### Мобильная проверка

- Карточки не вылезают за экран.
- Кнопки нажимаются удобно.
- Bottom sheet открывается и закрывается.

### После деплоя

- GitHub Actions показывает успешный `Deploy production`.
- Главная открывается без ошибки 500.
- CSS загрузился, страница не выглядит как страница без стилей.
- Кнопки Save/Сохранить работают.
- GitHub Actions, если нужен, запускается вручную.

## Перед крупными правками

### Главная страница

- Главная страница открывается.
- Месяцы и дни раскрываются.
- Карточки матчей видны.

### Прогнозы

- Можно нажимать `+` и `-`.
- Можно сохранить ставку.
- После сохранения ставка видна.
- Закрытый матч нельзя изменить.

### Завершённые матчи

- Итоговый счёт виден.
- Очки видны.
- “Ставки игроков” открываются.

### Таблица

- Таблица открывается.
- Очки отображаются.

### Профиль

- Профиль открывается.
- Прогнозы видны.

### Админка

- Админка открывается.
- Обновить матчи работает.
- Статус автообновления понятен.
- Можно добавить матч.
- Можно выставить результат.
- Можно пересчитать очки.

### Мобильная проверка

- Карточки не вылезают за экран.
- Кнопки нажимаются удобно.
- Bottom sheet открывается и закрывается.

## Если что-то сломалось

- Проверить главную страницу.
- Проверить прогнозы.
- Проверить завершённые матчи.
- Проверить таблицу.
- Проверить профиль.
- Проверить админку.
- Проверить мобильный вид.
- Проверить `Deploy production` в GitHub Actions после деплоя.

## Если проверка не прошла

- Не продолжать новые правки.
- Не делать новые commit поверх поломанного состояния.
- Сначала вернуть рабочее состояние сайта.
- Найти последний коммит.
- Посмотреть логи `Deploy production` и production-monitor.
- При необходимости откатиться.
